# Workshop Streaming - 2025-10-02

This repository contains examples demonstrating Streaming capabilities using Mastra.

## Structure

### 1. Basic example

```bash
cd workshop/basic
node intro.mjs
```

### 2. Mastra example

```bash
cd workshop/mastra
pnpm dlx tsx src/stream.ts
```

### 3. Mastra UI example

Start mastra app

```bash
cd workshop/mastra
pnpm dev
```

Start nextjs app

```bash
cd workshop/ui
pnpm dev
```
